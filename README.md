# NASEEJ — نَسِيج

A premium minimalist geometric symmetry puzzle for Android and the web.

## Included in this MVP

- Dark Premium visual identity with deep navy, turquoise, and warm gold accents.
- Arabic and English interface with RTL/LTR switching.
- Portrait-first responsive layout.
- 30 authored levels with gradually increasing difficulty.
- One-line tracing on the left half with automatic mirrored geometry.
- Touch, pointer, and mouse input; hint, undo, and reset controls.
- Local progress saving and sequential level unlocks.
- Daily challenge based on the UTC calendar date.
- Pattern share card generated as a PNG (native share sheet where supported, download fallback elsewhere).
- No ads, gambling, paid random rewards, characters, or music.
- Offline shell caching after the first browser load.
- Unit tests for level data, path rules, and progress saving.

## Requirements

- Node.js 22 or newer.
- npm 10 or newer.
- For Android builds: Android Studio and an Android SDK (Android Studio supplies the compatible JDK for its Gradle configuration).

## Create the Android project and APK

The source is configured for Capacitor 8.6.0. Current Capacitor 8 setup requires Node.js 22 or higher, Android Studio 2025.2.1 or later, and an Android SDK platform API 24 or higher. Android Studio supplies the compatible JDK. From this folder, run:

```bash
npm install
npx cap add android
node ./scripts/lock-portrait.mjs
npm run cap:sync
npx cap open android
```

The build helper also locks the native activity to portrait. To apply the custom launcher icon, open the Android project in Android Studio and use **New > Image Asset** on the `app` module, selecting `resources/icon-1024.png`. Then select the desired build variant and use **Build > Build Bundle(s) / APK(s) > Build APK(s)**. For a release APK, configure signing in Android Studio before generating the release build.

Alternatively, after the Android platform has been added and synced, build a debug APK from the terminal:

```bash
cd android
./gradlew assembleDebug
```

The debug APK is produced at `android/app/build/outputs/apk/debug/app-debug.apk`.

## Notes

- The initial MVP stores progress locally on the device. It does not use accounts, analytics, ads, or a backend.
- The daily challenge selects the same stage for all players on the same UTC date; it does not require a network connection.
- Android platform files are generated by `npx cap add android` on the build machine. This source package includes the complete Capacitor configuration and is ready for that step.

## Build an Android test APK from an iPad or phone (cloud build)

This repository includes `.github/workflows/android-apk.yml`. You do not need Android Studio on your mobile device to run this workflow:

1. Upload the contents of this project to a GitHub repository (the workflow file must remain at `.github/workflows/android-apk.yml`).
2. Open the repository in a browser and select **Actions**.
3. Select **Build NASEEJ Android APK**, then **Run workflow**. You can also trigger it by pushing a commit to `main` or `master`.
4. When the run finishes successfully, open the run and download the `naseej-debug-apk` artifact.
5. Extract the downloaded artifact. It contains `app-debug.apk`, which is for device testing, not Google Play production release.

The workflow runs the unit tests, builds the web app, generates the Capacitor Android project, syncs it, and builds a debug APK using a cloud Linux runner. The first run may take several minutes. A failed run must be diagnosed from the Actions log; it does not produce a valid APK.

For Google Play, prepare a signed Android App Bundle (AAB), verify the current target API requirement, complete store declarations and testing, and keep the upload keystore private. The debug APK from this workflow is not a store-ready release.
